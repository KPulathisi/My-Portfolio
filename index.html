01 — About
KP

I turn ideas into clean, working software — from database schema to the last pixel of the interface.

I'm Kavinda, an Associate Software Developer from Sri Lanka and currently at Ribelz Integrated, with an HND in IT from SLIATE — ATI Tangalle. I build role-based business systems, real-time web apps and APIs — with a soft spot for well-designed databases and interfaces that feel alive.

Lately I've been shipping React + TypeScript apps on Firebase and Supabase, and layered Node/Express backends. Before that, PHP, Java Swing and C# desktop systems taught me the fundamentals: solid data models, secure auth, and software that real people actually use.
